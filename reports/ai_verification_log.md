## Part 3 — Important Findings
### Finding 1: Mumbai Indians Wins
- Unfiltered recorded winners: 155
- Filtered wins (`result = 'win'`): 153
- Difference: 2 tied matches
- Both AI tools provided correct explanations.
- Database verification confirmed the difference.

### Finding 2: YS Chahal Bowling Wickets
- Gemini query result: 224
- ChatGPT query result: 228
- Missing dismissal category in Gemini SQL: `caught and bowled`
- Database-confirmed bowler-credited wickets: 228
- Resolution: Include `caught and bowled` in the SQL filter.

### Finding 3: First-Innings Score Bands
- An initial AI-generated query referenced `first_innings_runs`.
- The actual database view column was `first_innings_total`.
- The column name was corrected after inspecting the view schema.
- Verified score-band total: 1,187 matches.
